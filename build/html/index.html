Welcome to PlatoSim’s documentation!

The PLATO Simulator (PlatoSim) is an end-to-end software tool, designed to perform realistic simulations of the expected observations of the PLATO mission. PlatoSim simulates time series of CCD images by modelling the stellar field, the spacecraft systematics, the jitter of the spacecraft, the camera optics, the CCD and its electronics, and all important natural sources of noise.

PlatoSim is used by the PLATO Mission Consortium (PMC) for performance assessments of the mission and for scientific studies related to its core and complementary science programmes.

Where to start?

  • New to PlatoSim? Follow the Quickstart to install PlatoSim and run your first simulation in a few minutes.

  • Installing or updating: see the installation overview for the requirements and the two installation routes.

  • Running simulations: see Running PlatoSim. We recommend to use PlatoSim’s Python interface, which is explained in our Python tutorials.

  • Many cameras, imagettes, or light curves: have a look at the PLATOnium toolkit.

  • Something not working? See Troubleshooting.

  • How does it work? See the Architecture and the PlatoSim paper, which you should also cite when you use PlatoSim.
