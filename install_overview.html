Overview

Warning

PlatoSim has been tested on recent Linux (Ubuntu, Debian, Fedora) and Mac OS X systems. We cannot support Windows systems at the moment, so we advise Windows users to install a Virtual Machine (VM) and install PlatoSim inside the VM. Alternatively, if you are using Windows 10 or 11, you can use Windows Subsystem for Linux (WSL) instead.

PlatoSim can be installed in two ways:

  • Pre-built versions of PlatoSim3 via Conda – For Users (via Conda)

  • Download and build the software yourself – For Developers (from Source).

The latter option gives you the freedom to make changes to the code, but it is a more complex procedure and in most cases not needed.
